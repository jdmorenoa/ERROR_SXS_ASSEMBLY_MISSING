# Solución al Error 0x80073701 (ERROR_SXS_ASSEMBLY_MISSING)

Este repositorio contiene el script de PowerShell utilizado en el video de YouTube para solucionar el error de actualización 0x80073701 en Windows Server 2016, 2019 y 2022.

## 📺 Tutorial
Mira el video paso a paso aquí: ¡No Formatees! Arregla el error 0x80073701 (Assembly Missing) Definitivamente

## ⚠️ Descargo de Responsabilidad (Disclaimer)
Este script realiza modificaciones en el Registro de Windows.
* **Úsalo bajo tu propia responsabilidad.**
* Se recomienda encarecidamente realizar una **Copia de Seguridad (Backup)** o un Snapshot del servidor antes de ejecutarlo.

## 🛠️ Instrucciones de Uso
1. Descarga el archivo `Fix-Error-0x80073701.ps1`.
2. Abre PowerShell como Administrador.
3. Ejecuta el script.
4. Introduce la ruta de tu archivo CBS.log cuando se te solicite (o presiona Enter para la ruta por defecto).
